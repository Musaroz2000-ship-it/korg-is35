# KORG iS35 — русский гид

Одностраничное автономное приложение-справочник (index.html) для синтезатора **Korg iS35**
(Interactive Music Workstation, конец 1990-х). Синтезатор русифицировать нельзя (прошивка в ROM),
поэтому этот гид делает его понятным.

## Возможности

- **ИИ-помощник** — вкладка «ИИ» и плавающая кнопка 🤖 в любом разделе. Работает как мини-поисковая нейросеть: не требует готовых тем — анализирует любые слова вопроса, ищет по ВСЕМУ тексту руководства (42 готовых ответа, карточки панели/режимов/сценариев, словарь, 128 GM-звуков, 64 стиля), понимает формы слов и опечатки (нечёткое сравнение), знает русские названия («рояль», «труба», «вальс», «кантри»). Отвечает просто: блок «Проще говоря» + автоматическая расшифровка английских терминов из словаря. Кнопка отправки ➤, индикатор «думает», живые подсказки вопросов, «Новый диалог». Полностью офлайн, без интернета и ключей.

- **Панель** — интерактивная карта всех секций пульта (тёмная профессиональная тема): что написано на кнопках и что они делают в каждом режиме.
- **Режимы** — все 6 режимов + демо.
- **Как сделать** — 11 пошаговых сценариев: автоаккомпанемент, смена тембра, сплит/наложение, транспонирование, запись Backing Sequence, минусовки SMF с текстом, запись песни, микрофон и вокал-гармония, свой тембр, распознавание аккордов, сохранение данных.
- **Словарь** — ~70 терминов интерфейса с переводом и подсказкой, живой поиск.
- **Звуки · Стили** — как выбираются программы (384, банки A–F по 64), полный список General MIDI (128), стили (банк B11–B88), Keyboard Sets.
- **Дискета** — загрузка/сохранение/форматирование (MS-DOS 2DD/HD), Factory Preload, совместимость с дискетами i30/iS40/iS50/i40M.
- **О синте** — характеристики, задняя панель, поведение памяти (USER стирается при выключении!), типовые неполадки.

## Использование

Откройте `index.html` в любом браузере (телефон или ПК). Работает полностью офлайн,
внешних зависимостей нет.
