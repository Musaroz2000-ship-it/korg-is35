KORG iS35 · русский гид

Наглядный помощник к синтезатору: панель, режимы, сценарии, словарь, справочники

Нажми на любую секцию — увидишь, что написано на кнопках и что они делают в каждом режиме.

Если непонятная надпись мелкая или расположена над кнопкой — это её вторая функция и работает она у кнопки.

У iS35 шесть рабочих режимов. Кнопки MODE — слева вверху. При включении аппарат сам встаёт в ARR.PLAY.

Быстрое перемещение

  • EXIT/NO — назад на страницу 1 текущего режима; выход из подстраниц.
  • PAGE + / − — листать страницы режима (номер виден на дисплее).
  • Демо (16 демо-пьес): нажми одновременно ARR.PLAY + B.SEQ. Выбор демо — кнопками номеров; START/STOP — старт/стоп; EXIT/NO — выйти.

Жми на задачу — внутри пошаговый порядок кнопок, как в официальном руководстве.

Введи слово с экрана или кнопки — получишь перевод и подсказку.

Как выбираются тембры и стили + полные списки.

ПКак выбрать тембр (Program)Program / Program Change

Звуки iS35: 384 программы — 6 банков (A, B, C, D, E, F) по 64, номера внутри банка 11–88.

  • Нажми кнопку нужной дорожки (VOLUME/PROGRAM), затем в секции PROGRAM — банк и двухзначный номер.
  • Банк F = USER — сюда сохраняются отредактированные тембры. Если нажать F дважды, на дисплее появится «Dr» — наборы ударных.
  • В банках A и B живут 128 General MIDI звуков — их и ждут SMF-минусовки.

General MIDI — 128 звуков

В iS35 это банки A (1–64) и B (65–128). Номер = стандартный GM-номер.

Стили (аккомпанемент)

В памяти 128 стилей ROM + 16 пользовательских. Список ниже — банк B (стили B11–B88), как в руководстве (стр. 228).

Keyboard Sets (наборы клавиатуры)

Мгновенная смена готовой настройки клавиатуры. 3 банка (A, B, C) × 5 наборов — всего 15. Запись набора: настрой дорожки → REC/WRITE/LYRICS → Write Keyboard Set → ENTER/YES.

  • Банк A — дефолтные наборы под вокал.
  • Банк B — дефолтные наборы под «чистую гитару».
  • Наборы хранят: дорожки клавиатуры, тембры, октавы, эффекты и настройки Vocal/Guitar.

iS35 читает 3,5" дискеты 2DD/HD в формате MS-DOS (как у ПК).

Главное правило: записи (Backing Sequence, Song, новые программы, Global) живут в памяти только пока включено питание. Сохраняй на дискету перед выключением!

Загрузка и сохранение (DISK/GLOBAL → Page 1)

↑Загрузить данные с дискеты
  1. Вставь дискету, нажми DISK/GLOBAL.
  2. Page 1: Load All (всё) или Load One (один тип данных: аранжировка, стиль, программа, песня…), Load Global, Load Keyboard Set.
  3. CURSOR — выбрать файл/тип, ENTER/YES — подтвердить, EXIT/NO — отмена.
↓Сохранить данные на дискету
  1. Возьми чистую дискету, не защищённую от записи (одно закрытое окошко).
  2. DISK/GLOBAL → Page 1 → Save.
  3. Выбери, что сохраняешь (аранжировки, BSQ — максимум 10, песня в SMF, Keyboard Set…).
  4. ENTER/YES для записи. «Completed» — готово.
SСохранить песню как Standard MIDI File

Запиши песню в Song Edit → Page: Save → дискета в формате MS-DOS → ENTER/YES. Получишь обычный .MID, который читается компьютером.

FФорматировать дискету
  1. Возьми новую 3,5" HD дискету или ту, с которой не жалко данных.
  2. Дискета должна быть незащищённой: только одно закрытое окошко записи.
  3. DISK/GLOBAL → Page 1 → Utility → Format → ENTER/YES.
RВернуть заводские данные

«Factory Preload Data» — официальный архив с сайта Korg (дискета 365 КБ). Запиши его файлы на дискету и загрузи через Load All. Совместимость: читаются дискеты и данные i30, iS40, iS50, iS50B, i40M.

Если дискета не читается

  • Disk error — дискета защищена от записи: сдвинь окошко, чтобы закрылось одно.
  • Мусор/ошибка — дискета не MS-DOS или повреждена; отформатируй на компьютере или замени.
  • Чисти привод специальной чистящей дискетой; отсутствие «клацанья» при вставке — нормально для этого привода.
  • Не вытаскивай дискету, пока мигает индикатор дисковода.

Особое

Vocal/Guitar-секция: микрофон, гармонайзер (iS35 = iS40 + Vocal Harmony)

Годы выпуска

Конец 1990-х (≈1998–99)

Задняя панель

  • OUTPUT L/MONO, R — стерео выход на усилитель/микшер.
  • INPUT-IN — вход микрофона/гитары для Vocal/Guitar-секции.
  • MIDI IN 1 / IN 2 / OUT / THRU — при одном устройстве используй IN 1.
  • DAMPER — педаль сустейна (Korg PS-1/PS-2).
  • ASSIGNABLE PEDAL/SWITCH — программируемая педаль (XVP-10, EXP-2).
  • EC5 — внешний контроллер Korg EC5 (5 кнопок; Global Page 15).

Важное про память

  • Аранжировки A–B — ROM, USER — RAM. Изменения живут в памяти только до выключения.
  • Свои данные сохраняй регулярно на дискету — при сбое питания всё пропадает.
  • Через MIDI можно передать полный дамп данных (Global Page 22: MIDI Data Dump) на другой i-синт.

Если что-то не получается

  • Нет звука — проверь MASTER VOLUME, слайдеры дорожек, не включён ли MUTE (одновременное нажатие пары VOLUME-кнопок дорожки ставит/снимает mute).
  • START/STOP — только барабаны — Chord Scanning в OFF (все LED погашены). Нажми LOWER (или LOWER+UPPER = FULL).
  • Аккорды справа не берутся — Chord Scanning должен быть UPPER или FULL; в Fingered 2 играть минимум 3 ноты.
  • Слишком низкий левый звук — выбери дорожку Lower и нажми OCTAVE +.
  • Всё «замучило» — RESET возвращает секвенсор в начало и перезапускает детектор аккордов; в любой момент RESET = «MIDI Panic» (снимает застрявшие ноты).
  • Вернуть параметру заводское значение — нажми TEMPO/VALUE + и − одновременно.
  • Демо играет само — ты в Demo-режиме (случайно ARR.PLAY+B.SEQ). Нажми EXIT/NO.
